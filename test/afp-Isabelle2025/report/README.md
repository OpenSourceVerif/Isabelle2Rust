## 主要结论

扫描的三项直接失败分别是：AutoCorres2 的实际导入理论与扫描覆盖前提不匹配；Native_Word 原会话的 OCaml checking 使用 Pervasives 适配而失败；CZH_Elementary_Categories 在 cf_mapsI 的 HOL 自动证明中存储耗尽。228 个依赖受阻条目中，227 个的回执原因指向 Native_Word，1 个指向 CZH_Elementary_Categories。

导出的主要失败前提集中在缺少可执行代码方程、代码类型类实例不足、代码抽象类型入口限制、上下文中的构造子表示及共享预处理证明。Go 另有数字构造子名称解析和动态字符串字面量适配案例。已证明的共享前端源算法不终止有各入口自己的原始日志与结构证据，其他资源失败仍保留为未决，不按相似现象推断根因。
