# SBPF Rust Macro Validation

This directory contains only the Rust-side macro runner and glue harness for the
SBPF program-level validation suite.

The shared orchestration is in `../run_macro_sbpf.py`. This directory handles
the Rust-specific part of the path:

1. read the Isabelle-generated Cargo project:
   `test/sbpf/theory/stage1/bpf_generator/interp_test/`
2. install `interp_main.rs` as the generated crate's `src/main.rs`
3. build the generated crate with the fixed Rust toolchain
4. read the shared local data file `../../data/interp_in.json`
5. run the 146 Solana macro cases one by one, reporting elapsed time for each
   case and listing the slowest cases at the end

The shared data file is generated by `../gen_interp_json.py` from
`../sbpf_ocaml/test.ml`. That data-generation step is not Rust-specific, so it
lives one level up in `exec_semantics/`.

## Fixed Rust Environment

```sh
cargo +stable --version

rustc +stable --version
```

The Rust runners use `cargo +stable` by default and build generated crates with
`--release --locked`. They do not set `RUSTC_BOOTSTRAP` or enable unstable
features.

## Files

- `run_interp_macro.py` — Rust-specific runner used by `make macro_sbpf`.
- `interp_main.rs` — glue harness copied over the generated `interp_test`
  crate's `src/main.rs`; it reads `interp_in.json`, converts local `i64` data to
  exported `BigInt` values, calls `bpf_interp_test`, and reports results.
- `step_main.rs` — existing instruction-level harness for the later micro-test
  path.

## Running

```sh
# regenerate the shared interp JSON from test.ml (only needed if test.ml changes)
python3 test/sbpf/tests/exec_semantics/gen_interp_json.py


make macro_sbpf

# Optional diagnostic timeout. By default there is no per-case timeout.
RUST_CASE_TIMEOUT=30 make macro_sbpf
```

By default the Rust runner does not impose a per-case timeout. If a case is
slow, the runner prints the case name before starting it, so the current
long-running case is visible in the log. The summary also lists the slowest
cases from that run.
