The source graph contains extracted Isabelle facts. Realizations and decisions are revisable model claims; executed validation has separate scope and exact versions. Source names are canonical elaborated constants; instance_resolutions records concrete class-operation resolution where Isabelle can determine it. Occurrence edges do not prove runtime calls, aliases, range or ownership.
Read exact evidence using {request_entities:[{model_version:"current",id:"constant:Qualified.name",include_callers:true,include_dependencies:false}]}, {request_files:[{path:"src/lib.rs",code_version:"current code_version",start_line:1,end_line:80}]}, {request_sources:[{path:"catalogued path",start_line:1,end_line:80}]}, or {request_references:["catalogued reference"]}. Source closure reads can be large; request relevant operations and their callers/types first. Entire related Rust functions/files are supplied without clipping their bodies. Syntax references are conservative and may be ambiguous. Missing material stays requestable. Exact past turns/materials are available with request_materials and archived versions. No cross-task memory is used.
The current_mapping table includes implementation boundaries; a source definition is never erased by a Rust representation choice. A mapping does not prove equivalence. Whole-function replacements still implement that function's original contract. Original generic exports survive all adaptations. edit_protocol binds mutations to the current request snapshot without requiring a version echo. repair_execution preserves action rejections, exact recent rejected proposals and executed change records independently of conversation compaction. Applied does not mean verified; read checks and the original issue separately. Initial translation and quick refinement never receive test ABI or workload. Runtime diagnostic evidence is supplied only during repair, without performance results.
