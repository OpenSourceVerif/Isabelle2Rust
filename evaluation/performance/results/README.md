# Paper-facing RQ3 performance results

This directory tracks only the performance data currently used by the paper:

- `20260820-052719+0800/`: SBPF program and instruction workloads.
- `x64-20260820-053412+0800/`: x64 single-step workload.

Both result bundles contain the consolidated raw measurements, paper-facing
summaries, environment, configuration and binary hashes, correctness evidence,
and the commands used for the final measurements. Absolute paths in their
command and environment records are historical facts from the measurement host
and have intentionally not been rewritten.

Pilot measurements, per-invocation logs, reused source runs, and superseded
result bundles are retained in an author-side history archive outside the Git
repository. They are intentionally excluded from the paper-facing artifact.
